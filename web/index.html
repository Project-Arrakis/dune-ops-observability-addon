Time-series metrics

Grafana Dashboards

Prometheus · Grafana · Auto-provisioned

Time-series graphs powered by Prometheus and Grafana. Select a time range below or use the dashboard links. Dashboards auto-provision — no configuration required. If Grafana is not running, start it with dune metrics start.

Grafana dashboards are not available when the console is accessed over HTTPS or through a TLS-terminating reverse proxy (Cloudflare Tunnel, nginx, Traefik). The browser blocks mixed content — HTTP iframes inside an HTTPS page. To view dashboards, either: (1) access the console directly via HTTP on <your-server-ip>:8088, or (2) configure your reverse proxy to route /grafana/* to Grafana's localhost:3000 so the addon can use same-origin URLs (no mixed content).
